# Scampr Support Website

This repository contains the official support website for the Scampr tree climbing app, including legal documents, safety guidelines, and user support resources.

## 🌳 About Scampr

Scampr is a mobile application that helps outdoor enthusiasts discover, share, and safely climb trees. The app provides:

- **Smart Tree Discovery**: Find climbable trees based on location, difficulty, and features
- **Community Reviews**: Share experiences and safety information
- **Interactive Maps**: Explore trees with GPS integration
- **Safety Resources**: Comprehensive climbing guidelines and best practices

## 📋 Website Contents

- **index.html** - Main landing page with app overview
- **terms.html** - Terms of Service with safety disclaimers
- **privacy.html** - Privacy Policy covering data collection and usage
- **support.html** - User support, FAQ, and troubleshooting
- **safety.html** - Comprehensive tree climbing safety guidelines

## 🛡️ Safety First

Tree climbing is an inherently dangerous activity. This website provides essential safety information and legal disclaimers to ensure users understand the risks and responsibilities involved in tree climbing activities.
